A Python program that writes one sentence to /output/entry.txt: a pitch to a friend who has never coded — if they can explain their app idea to a friend, they can explain it to make.fun in the same plain words, with no code or jargon, while an AI agent builds the first version they can keep changing.

## Run it

```sh
python3 main.py
```
